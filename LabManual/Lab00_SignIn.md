## 推定時間：15分

## この Lab のねらい

これから 2 日間、Azure という環境の上にネットワークとサーバーを作ります。

その最初の一歩として、**自分のアカウントでサインインし、多要素認証を登録します**。

ここでつまずくと先に進めません。全員がそろってから次に進みます。

---

## 事前に用意するもの

| | 内容 |
|---|---|
| アカウント | 講師から配付された ID とパスワード |
| スマートフォン | 多要素認証で使います |
| ブラウザ | Microsoft Edge または Google Chrome |

> スマートフォンを持っていない場合は、講師に申し出てください。別の方法を用意します。

---

## タスク 1 - 認証アプリを入れる（5分）

多要素認証には、スマートフォンのアプリを使います。

### 1-1　アプリを入れる

スマートフォンで、次のアプリを入れてください。

- iPhone: App Store で「**Microsoft Authenticator**」を検索
- Android: Google Play で「**Microsoft Authenticator**」を検索

> すでに入っている場合は、そのまま使えます。

### 1-2　起動する

アプリを開きます。初回は次のような画面が出ます。

- 「プライバシーとデータ収集について」→ `[同意する]`
- 「アカウントを追加しましょう」→ この画面のまま待ちます

パソコン側の操作が終わるまで、この画面を開いたままにしておいてください。

---

## タスク 2 - サインインする（5分）

### 2-1　ポータルを開く

パソコンのブラウザで、次のアドレスを開きます。

```
https://portal.azure.com
```

> 会社のアカウントで自動的にサインインされてしまう場合は、
> ブラウザのシークレットウィンドウ（プライベートウィンドウ）で開いてください。

### 2-2　ID を入力する

「サインイン」の画面が出ます。配付された ID を入力し、`[次へ]` を選びます。

ID は次のような形式です。

```
intern01@ctctedu.onmicrosoft.com
```

> **自分の番号を確認してください。**他の人の番号でサインインしないでください。

### 2-3　パスワードを入力する

配付されたパスワードを入力し、`[サインイン]` を選びます。

### 2-4　詳細情報の要求

「詳細情報が必要」という画面が出ます。`[次へ]` を選びます。

---

## タスク 3 - 多要素認証を登録する（5分）

### 3-1　アプリの指定

「アカウントのセキュリティ保護」という画面が出ます。

`[次へ]` を 2 回選びます。QR コードが表示されます。

### 3-2　QR コードを読み取る

スマートフォンのアプリに戻ります。

1. 右上の `[+]` を選びます
2. 「職場または学校アカウント」を選びます
3. 「QR コードをスキャン」を選びます
4. カメラでパソコンの画面の QR コードを読み取ります

> カメラの利用を求められたら、許可してください。

### 3-3　番号を入力する

パソコンの画面に 2 桁の数字が表示されます。

スマートフォンに通知が届くので、その数字を入力し、`[はい]` を選びます。

### 3-4　完了

パソコンの画面に「通知が承認されました」と出ます。`[次へ]` `[完了]` と選びます。

---

## 完了の確認

Azure ポータルの画面が表示されていれば完了です。

画面の上部に、次のものが見えます。

| 位置 | 内容 |
|---|---|
| 左上 | 「Microsoft Azure」のロゴ |
| 中央 | 検索ボックス |
| 右上 | 自分のアカウント名 |

**右上のアカウント名が、配付された ID と一致していることを確かめてください。**

## うまくいかないとき

| 症状 | 確かめること |
|---|---|
| ID が違うと言われる | 綴りを確認。`@` 以降まで正確に入力する |
| パスワードが違うと言われる | 大文字と小文字を確認。数字の 0 と英字の O に注意 |
| 別のアカウントでサインインされる | シークレットウィンドウで開き直す |
| QR コードが読み取れない | 画面の明るさを上げる。カメラを近づけすぎない |
| 通知が届かない | アプリの通知が許可されているか確認 |
| 数字を入れる画面が出ない | アプリを一度閉じて開き直す |

> 5 分試して解決しない場合は、手を挙げて講師を呼んでください。
> ここで時間を使いすぎると、後の作業に影響します。

- 研修が終わったら、このアカウントは削除されます
- スマートフォンのアプリからも、研修後にアカウントを削除してください
