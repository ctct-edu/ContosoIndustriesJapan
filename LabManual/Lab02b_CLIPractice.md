## 推定時間：20分

Lab02 で接続したサーバーの中を、コマンドで見て回ります。
サーバーには画面もマウスもありません。文字で指示を出して操作します。この練習で使うコマンドは、Lab03 以降でそのまま使います。

> 注：このサーバーは、自分専用の仮想マシンです。コマンドを打ち間違えても、ほかの人には影響しません。ただし、この練習では `rm`（ファイルを削除するコマンド）は使いません。打たないでください。

## タスク 1 - いまいる場所を確認する（pwd）

1. Lab02 で接続した PowerShell の SSH セッションを開きます。`azureuser@vm-intern-YYMMDD-NN:~$` のプロンプトが表示されていることを確認します。

    > 注：SSH が切れている場合は、Lab02 のタスク 3 の手順で、もう一度接続してください。

2. 以下のコマンドを実行します。

    ```bash
    pwd
    ```

3. 以下のように表示されることを確認します。

    ```
    /home/azureuser
    ```

    > 注：`pwd` は「いまいる場所」を表示するコマンドです。`/home/azureuser` は、自分専用のフォルダーです。プロンプトの `~` も同じ場所を表します。

## タスク 2 - ファイルの一覧を見る（ls）

1. 以下のコマンドを実行します。

    ```bash
    ls
    ```

    何も表示されなければ正常です。自分のフォルダーには、まだ何も置いていないためです。

2. 続けて、以下のコマンドを実行します。

    ```bash
    ls -l
    ```

    こちらも何も表示されず、`total 0` と出れば正常です。

3. 続けて、以下のコマンドを実行します。

    ```bash
    ls -la
    ```

4. `.bash_history`、`.bashrc`、`.profile` など、名前が `.` で始まるファイルが表示されることを確認します。

    ```
    total 28
    drwxr-x--- 4 azureuser azureuser 4096 Oct 27 09:30 .
    drwxr-xr-x 3 root      root      4096 Oct 27 09:25 ..
    -rw-r--r-- 1 azureuser azureuser  220 Mar 31  2024 .bash_logout
    -rw-r--r-- 1 azureuser azureuser 3771 Mar 31  2024 .bashrc
    -rw-r--r-- 1 azureuser azureuser  807 Mar 31  2024 .profile
    ```

    > 注：表示される日付やファイルの数は、環境によって異なります。
    > `ls` の後ろに付ける `-l` や `-a` を「オプション」といいます。`-l` は詳しい表示、`-a` は `.` で始まる隠しファイルも含めた表示です。
    > 行の先頭の `-rw-r--r--` は権限を表します。読み方は、第 7 章で説明します。

## タスク 3 - 別の場所へ移動する（cd）

1. 以下のコマンドを実行して、`/etc` に移動します。

    ```bash
    cd /etc
    ```

    画面には何も表示されません。移動できたかどうかは、次の手順で確かめます。

2. 以下のコマンドを実行します。

    ```bash
    pwd
    ```

3. `/etc` と表示されることを確認します。

    > 注：`/etc` は、サーバーの設定ファイルが置かれている場所です。

4. 以下のコマンドを実行して、`/etc` の中身を見ます。

    ```bash
    ls
    ```

    設定ファイルの名前が、大量に流れて表示されます。

5. 以下のコマンドを実行して、自分のフォルダーに戻ります。

    ```bash
    cd ~
    ```

6. 以下のコマンドを実行し、`/home/azureuser` と表示されることを確認します。

    ```bash
    pwd
    ```

## タスク 4 - ファイルの中身を見る（cat）

1. 以下のコマンドを実行して、OS の情報を表示します。

    ```bash
    cat /etc/os-release
    ```

2. 以下のように表示されることを確認します。

    ```
    PRETTY_NAME="Ubuntu 24.04.x LTS"
    NAME="Ubuntu"
    VERSION_ID="24.04"
    ```

    > 注：ほかにも数行表示されます。`Ubuntu 24.04` と出ていれば、Lab02 で選んだイメージどおりです。

3. 続けて、以下のコマンドを実行して、サーバーの名前を表示します。

    ```bash
    cat /etc/hostname
    ```

4. 自分が Lab02 で付けた VM の名前（`vm-intern-YYMMDD-NN`）が表示されることを確認します。

## タスク 5 - 管理者の権限で実行する（sudo）

1. 以下のコマンドを実行します。パスワード情報が入っているファイルです。

    ```bash
    cat /etc/shadow
    ```

2. 以下のように、拒否されることを確認します。

    ```
    cat: /etc/shadow: Permission denied
    ```

    > 注：一般の利用者には、このファイルを見る権限がありません。エラーではなく、意図した動作です。

3. 続けて、`sudo` を付けて実行します。

    ```bash
    sudo cat /etc/shadow
    ```

4. 今度は中身が表示されることを確認します。

    > 注：`sudo` は「この一回だけ、管理者として実行する」という指示です。実行が終われば、また一般の利用者に戻ります。
    > 表示された内容は、画面の写真やスクリーンショットに残さないでください。画面共有をしている場合は、すぐに次の手順に進んでください。

5. 以下のコマンドを実行して、画面を整理します。

    ```bash
    clear
    ```

これで Lab02b は完成です。この SSH セッションは、そのまま開いておいてください。Lab03 でも使います。

## うまくいかないとき

| 症状 | 原因と対処 |
|---|---|
| `command not found` と出る | コマンドの綴りの間違いです。`pwd`、`ls`、`cd`、`cat`、`sudo` を打ち直してください |
| `No such file or directory` と出る | 場所の綴りの間違いです。`/etc/os-release` の `/` の位置、`-` の有無を確認してください |
| `cd` の後に何も表示されない | 正常です。`pwd` で場所を確認してください |
| SSH が切れてしまった | Lab02 のタスク 3 の手順で、もう一度接続してください |
