# AI チャット サンプルサイト

CTC FY26 インターンシップ SIer 体験研修で使用する、生成 AI チャットサイトのサンプルです。
自分で構築した Azure VM 上の nginx に配置し、Azure AI Foundry に接続して動かします。

## ファイル構成

| ファイル | 役割 | 編集 |
| --- | --- | --- |
| `index.html` | 画面の骨組み | 発展課題で編集 |
| `style.css` | 見た目（色・レイアウト） | 発展課題で編集 |
| `app.js` | チャットの動作、AI との通信 | 発展課題で編集 |
| `config.js` | 接続先・API キーなどの設定 | **必ず編集** |

## 使い方

### 1. サイトを取得する

VM に SSH 接続し、リポジトリを取得します。

```bash
git clone https://github.com/ctct-edu/ContosoIndustriesJapan.git
```

### 2. nginx の公開ディレクトリに配置する

```bash
sudo cp -r ContosoIndustriesJapan/* /var/www/html/
```

### 3. 設定ファイルを書き換える

`/var/www/html/config.js` を開き、`<< >>` で囲まれた 3 か所を、Azure AI Foundry で取得した値に置き換えます。

```bash
sudo nano /var/www/html/config.js
```

| 項目 | 書き込む値 |
| --- | --- |
| `ENDPOINT` | AI Foundry のエンドポイント URL（末尾の `/` は付けない） |
| `DEPLOYMENT` | モデルのデプロイ名 |
| `API_KEY` | API キー |

> 注：API キーはブラウザから読み取れる状態になります。この構成は研修用の簡易的なものであり、実務では API キーをサーバー側で保持します。

### 4. 動作を確認する

ブラウザで `http://<VM のパブリック IP アドレス>` を開き、メッセージを送信して応答が返ることを確認します。

## うまく動かないとき

画面に表示されるエラーメッセージを手がかりに、次を確認します。

| 症状 | 確認すること |
| --- | --- |
| 「config.js の設定が済んでいません」と表示される | `<< >>` の 3 か所を書き換えたか、ファイルを保存したか |
| 「API キーが正しくありません」（401） | `API_KEY` の値、コピー時に余分な空白が入っていないか |
| 「接続先が見つかりません」（404） | `ENDPOINT` の末尾に `/` が付いていないか、`DEPLOYMENT` の綴り |
| 「接続できませんでした」 | `ENDPOINT` の URL 全体、ブラウザの開発者ツール（F12）のコンソール |
| 画面が真っ白 | ファイルの配置先、`config.js` の記述（カンマの消し忘れなど） |

変更が画面に反映されないときは、ブラウザで Ctrl + F5 を押して再読み込みします。

## 発展課題のヒント

- `config.js` の `SYSTEM_PROMPT` を書き換えて、AI の役割や口調を変える
- `style.css` の `:root` にある色の設定を変えて、配色を作り替える
- 会話をすべて消す「クリア」ボタンを追加する
- 応答を待っている間に経過時間を表示する
