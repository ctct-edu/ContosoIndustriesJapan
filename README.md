# ContosoIndustriesJapan

「SIer 体験研修」で使用する、演習手順およびサンプルデータの置き場です。

架空のクライアント企業「Contoso Industries Japan」を相手にした案件を通じて、要件定義から設計・構築・報告までの SIer の一連の業務を、講義ではなく手を動かす形で体験します。

## この演習で扱うこと

5 日間のプログラムのうち、このリポジトリは主に **Day3・Day4（構築フェーズ）** で使用する、Azure 上のインフラ構築とアプリケーション公開の演習手順を扱います。

- Azure 上に、1 人につき 1 つの仮想ネットワーク・仮想マシン環境を構築する
- 自分の仮想マシンに Web サーバー（nginx）を立て、生成 AI チャットサイトを公開する
- 公開したチャットサイトを、Azure AI Foundry に接続して実際に動かす

Day1（要件定義）・Day2（設計）・Day5（報告）の資料は、別リポジトリまたは別資料で管理しています。

## シナリオ：Contoso Industries Japan

演習全体の背景となる、架空のクライアント企業の設定です。

- ドイツ資本の Tier 1 自動車部品メーカーの日本法人。愛知県小牧市に主力工場を持つ
- 従業員数約 840 名。工場は 3 交代制で稼働しており、夜間帯は IT 担当者に質問できる相手がいないという課題を抱えている
- この会社から「工場向けの新しいシステム基盤と、簡易な社内向けサイトを作ってほしい」という案件を受けたという想定で演習を進める

| リソース | 作成する Lab | 役割 |
|---|---|---|
| リソース グループ・VNet・NSG | Lab01 | 環境の土台となるネットワーク |
| 仮想マシン（Ubuntu） | Lab02 | Web サーバーを動かすホスト |
| nginx・サンプルサイト | Lab03 | チャットサイトの公開 |
| Azure AI Foundry | Lab04 | チャットサイトが応答する AI モデル |

## フォルダー構成

| フォルダー | 内容 |

| [`sampleChatbotSite`](./sampleChatbotSite) | 演習内で配置する、生成 AI チャットサイトのサンプルデータ一式 |

## 演習の流れ

1. `LabManual` の Lab01 から順に進めます。詳細は [`LabManual/README.md`](./LabManual/README.md) を参照してください。
2. Lab01・Lab02 で、自分専用の Azure ネットワークと仮想マシンを構築します。
3. Lab03 で、`sampleChatbotSite` の中身を自分の VM 上の nginx に配置します。この時点ではチャットは動作しません（接続先が未設定のため）。
4. Lab04 で Azure AI Foundry を構築し、`sampleChatbotSite/config.js` に接続情報を設定して、チャットを動かします。
5. 発展課題として、`sampleChatbotSite` の見た目や AI の応答スタイルを自分たちで作り替えます。

## 前提条件

- Azure Portal にサインインできるアカウント（講師から配布）
- ローカル PC（Windows、PowerShell を使用）
- 各自のリソース名は `rg-intern-YYMMDD-NN` のように、実施日とチーム番号を含む形で統一します（詳細は `LabManual` 各手順を参照）
